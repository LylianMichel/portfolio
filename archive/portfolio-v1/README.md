# Références temporaires de l'ancien portfolio

Ces fichiers ne sont importés ni par App, ni par Desktop. Ils ne constituent pas
une seconde application : aucun point d'entrée n'est conservé ici.

Les textes originaux et modèles de présentation sont conservés pour aider à
reprendre les prochains TP. Leurs imports visent les données uniques de src/os.
Les classes lm-* et la feuille historique ne doivent pas être importées dans
LylianOS sans adaptation ciblée.

Les tests historiques continuent de tourner avec npm test. Les fichiers TS/TSX
archivés restent vérifiés par TypeScript : l'archive ne masque pas les erreurs.
Les utilitaires Matrix/SOURCE/PLAY présents ici ne servent qu'à ces tests et
ne sont pas inclus dans le bundle du site.

À retirer progressivement après récupération des textes ou composants utiles.
La liste exhaustive des déplacements se trouve dans docs/migration-inventory.json.
