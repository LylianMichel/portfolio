# LylianOS

Le bureau actuel et les TP réalisés définissent l'identité visuelle : paysages
alpins, surfaces claires en verre dépoli, accents lavande, fenêtres arrondies et
icônes Lucide aux couleurs définies dans src/os/config/applications.ts.

Conserver cette direction. La feuille active est src/os/os.css ; src/styles.css
contient uniquement la base commune. Les effets Matrix et SOURCE / PLAY ne
font pas partie de LylianOS.

Les transitions doivent respecter prefers-reduced-motion. Les données réelles
restent dans src/os/data. Le CV et les paysages originaux restent dans public.

L'ancienne direction artistique est conservée comme référence historique dans
archive/portfolio-v1/DESIGN.md ; ses classes lm-* ne doivent pas être réactivées
globalement dans le bureau.
